# familyboard-support

Support page for **Family Board** (iOS), served via GitHub Pages at
<https://dakl.github.io/familyboard-support>.

The whole site is `index.html` — a single static page with contact info,
FAQ, and privacy notes. Edit and push; GitHub Pages republishes within a
minute or two.

## Local preview

```sh
python3 -m http.server -d . 8000
# open http://localhost:8000
```

Or just open `index.html` directly in a browser.
